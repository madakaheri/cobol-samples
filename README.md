## わかったこと

### 文法は美しいが使い所が限られる

本当に文法だけは美しく、動作ステップが視覚的に理解しやすかったですが、最初の変数のバイト数指定の段階から今後使っていける言語では無いと判断しました。

これで作成したサービスがお役所や銀行系のあの仕上がりになるのも納得できます。

決して悪い言語という訳ではありませんが本当に使い所が限られてしまうため、他の部分を別言語で作るのであればそっちの言語で統一して作った方が管理しやすいでしょう。  

VSCodeだけでこの言語を扱うのもマッチしていない感じがしますし、経済圏が出来上がっており有料のIDEばかりな所も厳しい要因です。

いやいや、どこかCOBOLの生きる場所で使いたい気持ちはあるのですが..
