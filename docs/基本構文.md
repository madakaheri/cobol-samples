# COBOLの基礎知識

## プログラム構造
COBOL プログラムは 4 つの division で構成されます。各 division にはセクションやパラグラフを定義し、処理の流れを組み立てます。

| Division | 役割 |
| --- | --- |
| IDENTIFICATION DIVISION | プログラムの名前や作者情報を記述 |
| ENVIRONMENT DIVISION | 実行環境・ファイル入出力の設定 |
| DATA DIVISION | 変数やファイルレコードなどのデータ定義 |
| PROCEDURE DIVISION | 実際の処理手順をステップ順に記述 |

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. SAMPLE.
       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  WS-MESSAGE    PIC X(20) VALUE "HELLO COBOL".
       PROCEDURE DIVISION.
           DISPLAY WS-MESSAGE
           STOP RUN.
```

## データ定義のキホン
- **レベル番号**: `01` から階層構造を表現。`01` は最上位、`05` や `10` で下位項目を定義できます。
- **PICTURE 句 (PIC)**: 変数の型と桁数を指定。
  - 数値: `9` (数字1桁), `S9` (符号付き), `V` (暗黙小数点), `COMP-3` (パック10進)
  - 文字列: `X` (任意文字), `A` (アルファベット)
- **VALUE 句**: 初期値を設定。
- **REDEFINES / OCCURS**: 同じ領域の再解釈や配列定義に使用。

```cobol
       01  WS-AMOUNT      PIC S9(5)V99 VALUE 0.
       01  WS-NAME        PIC X(20).
       01  WS-DATES.
           05  WS-YEAR    PIC 9(4).
           05  WS-MONTH   PIC 9(2).
           05  WS-DAY     PIC 9(2).
```

## 基本命令
- `MOVE A TO B` : 値の代入
- `COMPUTE B = A * 2` : 四則演算や関数
- `IF ... ELSE ... END-IF` : 条件分岐
- `EVALUATE` : switch に近い多岐分岐
- `PERFORM PARA-1` : パラグラフやセクションを呼び出し、繰り返しも記述可能
- `DISPLAY` / `ACCEPT` : 画面入出力

```cobol
       IF WS-AMOUNT > 0
           DISPLAY "正の値"
       ELSE
           DISPLAY "0 以下"
       END-IF

       PERFORM VARYING IDX FROM 1 BY 1 UNTIL IDX > 5
           DISPLAY IDX
       END-PERFORM
```

## ファイル・入出力の雛形
```cobol
       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT INFILE ASSIGN TO "input.dat"
               ORGANIZATION IS LINE SEQUENTIAL.

       DATA DIVISION.
       FILE SECTION.
       FD  INFILE.
       01  IN-REC.
           05  IN-NAME   PIC X(20).
           05  IN-AGE    PIC 9(3).

       PROCEDURE DIVISION.
           OPEN INPUT INFILE
           READ INFILE AT END
               MOVE 1 TO WS-EOF-FLAG
           END-READ
           CLOSE INFILE
           STOP RUN.
```

## 学習の進め方
1. division ごとに役割を理解し、既存サンプルのどこに記述があるか確認する
2. 変数定義 (PICTURE 句) を自分の言葉で説明できるようにする
3. PERFORM や IF を組み合わせた小さな処理を実装し、`DISPLAY` で結果を可視化する
