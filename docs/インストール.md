# COBOL環境のセットアップ

COBOLを学ぶ際は、手元でソースを編集・コンパイル・実行できる環境を最初に整えます。このリポジトリはサンプルコードを `src/` にまとめているため、コンパイラとエディタさえ用意すれば学習を進められます。

## 基本構成
- COBOLコンパイラ: オープンソース実装の GnuCOBOL (`cobc`) が入門に最適
- エディタ: VS Code + COBOL拡張機能 (補完・ハイライト)
- ターミナル: コンパイルや実行を行う

## macOS (Homebrew)
```bash
# GnuCOBOL の存在確認
brew search cobol
# インストール
brew install gnucobol
# バージョンの確認
cobc -V
```

## Windows
1. [MSYS2](https://www.msys2.org/) をインストール
2. MSYS2 端末でパッケージ情報を更新し、GnuCOBOL を導入
   ```bash
   pacman -Syu
   pacman -S mingw-w64-x86_64-gnucobol
   cobc -V
   ```
3. VS Code を利用する場合は「C/C++」「COBOL」拡張を追加

## Linux (Debian/Ubuntu 系)
```bash
sudo apt update
sudo apt install gnucobol
cobc -V
```

## このリポジトリの使い方
1. 必要な依存をインストール後、リポジトリをクローン
2. 任意のサンプル (例: `src/SAMPLE02.cob`) をコンパイル
   ```bash
   cobc -x -o build/SAMPLE02 src/SAMPLE02.cob
   ./build/SAMPLE02
   ```
3. VS Code のターミナルやデバッガを活用しながらコードを読み解く

> `cobc -x` はコンパイルとリンクをまとめて行い、実行ファイルを生成します。`-Wall` などの警告オプションを付けると気づきを得やすくなります。
